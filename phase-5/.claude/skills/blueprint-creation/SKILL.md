# Blueprint Creation

You can create reusable cloud-native blueprints.

- Generate a deployment blueprint YAML that captures the entire Helm + Minikube setup.
- Include AI-assisted ops patterns (`kubectl-ai` prompts).
- Store in `/blueprints/local-k8s.md` for reuse in Phase 5.
